# Skill: MCP Tool Design

## When to Use This Skill
- Designing MCP server tools
- Exposing backend operations to AI agents

## How This Skill Works
1. Identify AI-required operations
2. Create one tool per operation
3. Define inputs and outputs clearly
4. Enforce user scoping
5. Define error behavior

## Output Format
- Tool name
- Purpose
- Parameters
- Return values
- Error cases

## Quality Criteria
- Stateless tools
- Single responsibility
- No AI logic inside tools
