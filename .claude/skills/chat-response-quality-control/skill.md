# Skill: Chat Response Quality Control

## When to Use This Skill
- Validating chatbot responses
- Improving UX and tone

## How This Skill Works
1. Review clarity and tone
2. Confirm action acknowledgment
3. Simplify language
4. Improve friendliness
5. Handle errors gracefully

## Output Format
- Final user-facing response text

## Quality Criteria
- Polite and human-like
- No technical jargon
- Clear outcome communication
