# Skill: Planning (Plan Writer)

## When to Use This Skill
- Specification is approved
- User requests `/sp.plan`
- System needs execution sequencing

## How This Skill Works
1. Break system into logical components
2. Define build order and dependencies
3. Separate frontend, backend, AI, MCP concerns
4. Ensure no scope expansion
5. Align strictly with the specification

## Output Format
- High-level phases
- Component responsibilities
- Dependency order
- Explicit non-goals

## Quality Criteria
- No new features
- Clear execution order
- Spec-aligned plan
