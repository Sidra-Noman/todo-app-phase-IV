# Skill: Specification Writing (Spec Writer)

## When to Use This Skill
- User requests `/sp.specify`
- System requirements need formal definition
- AI, MCP, or chatbot behavior must be specified

## How This Skill Works
1. Identify goals, scope, and constraints
2. Convert requirements into structured sections
3. Write user stories for all actors
4. Define APIs, MCP tools, and agent behavior
5. Add acceptance criteria and error cases
6. Enforce stateless and Phase III constraints

## Output Format
- Goal & scope
- User stories
- Architecture overview
- MCP tool definitions
- Agent behavior rules
- Data models
- Error cases
- Acceptance criteria

## Quality Criteria
- Defines WHAT, not HOW
- No unauthorized features
- Fully testable requirements
- MCP-first and stateless
