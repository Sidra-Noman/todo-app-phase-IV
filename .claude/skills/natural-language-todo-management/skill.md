# Skill: Natural Language Todo Management

## When to Use This Skill
- User interacts with chatbot
- Natural language task management required

## How This Skill Works
1. Interpret user intent
2. Select correct MCP tool
3. Ask clarification if needed
4. Invoke tool with correct parameters
5. Confirm action clearly

## Output Format
- Friendly confirmation message
- Task summary (if applicable)
- Error explanation (if needed)

## Quality Criteria
- Correct tool usage
- No direct database access
- Clear confirmations
